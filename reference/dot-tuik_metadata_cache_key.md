# Build a credential-specific metadata cache key

Build a credential-specific metadata cache key

## Usage

``` r
.tuik_metadata_cache_key(agency, id, version, api_key = NULL)
```

## Arguments

- agency:

  Metadata agency.

- id:

  Metadata identifier.

- version:

  Metadata version.

- api_key:

  Optional API key.

## Value

A credential-specific cache key.
